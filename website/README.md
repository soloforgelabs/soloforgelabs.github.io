# SoloForge Labs Website Implementation Space 🌐

Здесь будет жить исходный код веб-сайта **SoloForge Labs** (https://soloforgelabs.github.io).

## Архитектура:
* **Frontend:** Vite + React + TypeScript
* **Styling:** Tailwind CSS (Obsidian Dark Theme)
* **Icons:** Lucide React
* **Deployment:** Автоматическая сборка и деплой на GitHub Pages

Структура будет инициализирована, когда мы перейдем к этапу реализации.
