## 🚀 Suite & Products

* ⚡ **[BlinkScribe](../BlinkScribe)** — Ultra-fast, featherweight Windows voice dictation powered by cloud Groq Whisper & Llama (<60MB RAM).
* 🛡️ **[DeskScribe](../DeskScribe)** — 100% Offline-First private voice dictation powered by local Whisper (`faster-whisper`) & local GGUF models.

* 💓 **VitalPulse (In Dev)** — Daily personal health telemetry (blood pressure logging, hydration monitor, medication reminders).
